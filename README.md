### [1 · A response rate you can read before the responses have arrived](01-maturity-adjusted-response-rate)

Direct mail replies take about two months to arrive, so every recent campaign
looks like a failure. Weighting each piece by how much of its response window
has elapsed fixes it. Tested against data where I set the true rate myself:
raw scoring reads young campaigns at **0.138%** when the truth is **0.300%**.

`SQL Server` · `DAX` · `Python` · *why the adjustment adds variance as it removes bias*

### [2 · A statistically significant finding that cannot possibly be true](02-unit-of-analysis-trap)

A reply rate that climbs convincingly with the number of letters sent, with
confidence intervals that do not overlap — in a dataset where **every letter
was posted on the same day**. A unit-of-analysis error, and what it costs: the
wrong reading sends the budget to re-mailing, the right one sends it somewhere
cheaper.

`Python` · `statistics` · *why significance testing does not protect you from this*
